# ⚽ مچ‌روز — MatchRooz

**سایت نتایج زنده و لحظه‌ای فوتبال**، آماده‌ی نصب روی هاست cPanel.

بدون نیاز به دیتابیس، بدون نیاز به Node.js، بدون نصب پکیج.
فقط فایل‌ها را آپلود کنید و سایت بالا می‌آید.

---

## ۱) نصب سریع (۳ دقیقه)

۱. وارد **cPanel** شوید و **File Manager** را باز کنید.
۲. وارد پوشه‌ی `public_html` شوید.
۳. فایل `matchrooz.zip` را **Upload** کنید.
۴. روی فایل زیپ راست‌کلیک کنید و **Extract** بزنید.
۵. تمام! آدرس سایت خود را باز کنید: `https://yourdomain.com`

> اگر می‌خواهید سایت در زیرشاخه باشد (مثلاً `yourdomain.com/live`)،
> فایل‌ها را داخل پوشه‌ی `public_html/live` استخراج کنید. برنامه با
> مسیرهای نسبی نوشته شده و در زیرشاخه هم بدون تغییر کار می‌کند.

### بررسی سلامت نصب

بعد از نصب، این آدرس را باز کنید:

```
https://yourdomain.com/api/index.php?action=health
```

باید یک خروجی JSON ببینید. معنی فیلدها:

| فیلد | یعنی چه |
|---|---|
| `provider` | منبع دادهٔ فعال (`demo` یا `apifootball` یا `thesportsdb`) |
| `php` | نسخهٔ PHP هاست (باید ۷٫۰ یا بالاتر باشد) |
| `curl` | آیا cURL فعال است (برای اتصال به API واقعی لازم است) |
| `cache_write` | آیا پوشهٔ کش قابل نوشتن است (باید `true` باشد) |

اگر `cache_write` برابر `false` بود، در File Manager روی پوشهٔ
`api/cache` راست‌کلیک کنید → **Change Permissions** → مقدار **755**
(و اگر جواب نداد **775**) را بگذارید.

## ۲) حالت نمایشی و دادهٔ واقعی

سایت به‌صورت پیش‌فرض در **حالت نمایشی (demo)** نصب می‌شود:

* بلافاصله کار می‌کند و نیازی به کلید API ندارد.
* بازی‌ها **واقعاً زنده جلو می‌روند**: دقیقه بالا می‌رود، گل‌ها در طول
  بازی اضافه می‌شوند و وضعیت از «شروع نشده» به «نیمه اول» و ... تغییر می‌کند.
* نام تیم‌ها و لیگ‌ها واقعی است، اما **نتایج، ترکیب‌ها و رویدادها
  ساختگی و شبیه‌سازی‌شده‌اند** و ارزش خبری ندارند.
* ساعت شروع بازی‌ها عمداً در کل شبانه‌روز پخش شده تا در هر ساعتی که
  سایت را باز کنید چند بازی زنده ببینید.

برای نمایش **نتایج واقعی**، باید یک منبع داده را وصل کنید (بخش بعد).

## ۳) اتصال به نتایج واقعی

### گزینهٔ الف: API-Football (پیشنهادی)

کامل‌ترین گزینه؛ رویداد لحظه‌ای، آمار، ترکیب و جدول را می‌دهد.

۱. در <https://dashboard.api-football.com> ثبت‌نام کنید (پلن رایگان: ۱۰۰ درخواست در روز).
۲. کلید خود را کپی کنید.
۳. فایل `api/config.php` را ویرایش کنید:

```php
'provider' => 'apifootball',

'apifootball' => [
    'key'      => 'کلید_خودتان_را_اینجا_بگذارید',
    'host'     => 'v3.football.api-sports.io',
    'timezone' => 'Asia/Tehran',
],
```

اگر کلید را از **RapidAPI** گرفته‌اید، فقط `host` را عوض کنید:

```php
'host' => 'api-football-v1.p.rapidapi.com',
```

### گزینهٔ ب: TheSportsDB

ارزان‌تر و ساده‌تر، ولی رویداد لحظه‌ای و ترکیب نمی‌دهد:

```php
'provider' => 'thesportsdb',
'thesportsdb' => [ 'key' => '3' ],
```

### مهم: مدیریت سهمیهٔ درخواست

پلن رایگان API-Football فقط **۱۰۰ درخواست در روز** می‌دهد. برای اینکه
سهمیه زود تمام نشود، مقدار کش را در `api/config.php` بالا ببرید:

```php
'cache' => [
    'live'  => 60,    // به‌جای ۲۵ ثانیه
    'today' => 300,
    'other' => 3600,
],
```

کش سمت سرور است، پس **همهٔ بازدیدکنندگان** از یک پاسخ ذخیره‌شده
استفاده می‌کنند؛ یعنی ۱۰۰۰ بازدیدکننده هم سهمیهٔ شما را نمی‌سوزانند.

## ۳٫۵) نام فارسی تیم‌ها و لوگوها

### ترجمهٔ خودکار نام‌ها

سرویس‌های داده نام تیم‌ها را انگلیسی می‌فرستند. مچ‌روز یک جدول ترجمه
دارد که آن‌ها را فارسی می‌کند — بیش از **۳۳۰ باشگاه**، **۷۰ لیگ و جام**
و **۹۰ کشور**، شامل لیگ برتر خلیج فارس.

این کار هوشمند انجام می‌شود؛ یعنی همهٔ این شکل‌ها به یک تیم می‌رسند:

```
Manchester City  /  Man City  /  Man City FC   →  منچسترسیتی
AC Milan         /  Milan                      →  میلان
Atlético Madrid  /  Atletico Madrid            →  اتلتیکو مادرید
Beşiktaş         /  Besiktas                   →  بشیکتاش
```

نام‌های ناشناس دست‌نخورده نمایش داده می‌شوند، پس هیچ تیمی حذف نمی‌شود.

**افزودن یا تغییر یک نام** — فایل `api/lib/data/teams.php`:

```php
'crystal palace' => ['کریستال پالاس', '#1B458F', '#C4122E'],
//   ↑ نام انگلیسی      ↑ فارسی        ↑ رنگ اول  ↑ رنگ دوم
```

کلید را با حروف کوچک و بدون `FC` و `SC` بنویسید. لیگ‌ها و کشورها هم در
`api/lib/data/misc.php` هستند.

برای خاموش کردن ترجمه: در `api/config.php` مقدار `'localize' => false`.

### لوگوی تیم‌ها

سایت لوگو را به این ترتیب پیدا می‌کند:

۱. **لوگوی رسمی سرویس داده** — وقتی به API-Football یا TheSportsDB وصل
   باشید، آدرس لوگوی هر تیم را خود سرویس می‌فرستد و خودکار نمایش
   داده می‌شود. کاری لازم نیست بکنید.

۲. **فایل‌های خودتان** — اگر لوگوهایی دارید که اجازهٔ استفاده از آن‌ها
   را دارید، در `assets/img/teams/` بگذارید (مثلاً `real-madrid.png`)
   و در `config.php` بنویسید `'local' => true`.

۳. **سپر تولیدشده** — اگر هیچ‌کدام نبود، سایت خودش یک سپر با **رنگ‌های
   واقعی همان باشگاه** و حروف اول نامش می‌کشد. برای همین حتی در حالت
   نمایشی هم هر تیم نشان درست و متمایز خودش را دارد.

> نشان باشگاه‌ها علامت تجاری ثبت‌شده است و همراه این برنامه توزیع
> نمی‌شود. راهنمای کامل در `assets/img/teams/README.txt` است.

## ۳٫۶) لیگ‌هایی که نمایش داده می‌شوند

در حالت نمایشی **۲۷ لیگ و جام** فعال است و هر روز برنامهٔ کامل دارند
(حدود **۱۵۶ بازی در روز**):

| منطقه | لیگ‌ها |
|---|---|
| **ایران** | لیگ برتر خلیج فارس (۲۰ تیم)، لیگ آزادگان |
| **آسیا** | لیگ قهرمانان آسیا، عربستان، قطر، امارات، ژاپن، کره جنوبی |
| **جام‌های اروپا** | لیگ قهرمانان، لیگ اروپا، لیگ کنفرانس |
| **اروپا** | انگلیس و چمپیون‌شیپ، لالیگا، سری آ، بوندسلیگا، لوشامپیونه، پرتغال، هلند، ترکیه، بلژیک، اسکاتلند، یونان |
| **آمریکا** | برزیل، آرژانتین، ام‌ال‌اس، مکزیک |

ترتیب نمایش را در `api/config.php` با `featured_leagues` عوض کنید؛
هر لیگی بالاتر باشد، بالاتر نشان داده می‌شود. لیگ ایران به‌صورت
پیش‌فرض اول فهرست است.

> در حالت واقعی (با کلید API)، لیگ‌هایی نمایش داده می‌شوند که خود
> سرویس برای آن روز برنامه دارد.

## ۴) امکانات سایت

**نمایش نتایج**
* نتایج زنده با دقیقهٔ در حال شمارش و نشانگر قرمز
* نوار بازی‌های زنده در بالای صفحه
* گروه‌بندی بر اساس لیگ، با امکان باز و بسته کردن
* فیلتر: همه / زنده / شروع شده / پایان‌یافته / شروع نشده / دنبال‌شده
* جست‌وجوی زنده در تیم‌ها و لیگ‌ها
* نوار تاریخ **شمسی** — از **۳ روز پیش تا ۴ روز آینده**
  (۳ روز پیش، ۲ روز پیش، دیروز، امروز، فردا، پس‌فردا، ۳ و ۴ روز دیگر)
* فیلتر **شروع شده** — بازی‌هایی که سوت آغازشان زده شده
  (چه در جریان باشند، چه تمام‌شده)
* دکمهٔ **جمع کردن / باز کردن همهٔ لیگ‌ها** برای مرور سریع
* نشان (سپر) هر تیم با رنگ‌های واقعی باشگاه

**صفحه‌ها**
* **نتایج زنده** — بازی‌های هر روز
* **جدول‌ها** — رده‌بندی با رنگ‌بندی سهمیهٔ اروپا و منطقهٔ سقوط
* **گلزنان** — برترین گلزنان هر لیگ با گل، پاس گل و پنالتی

**جزئیات هر بازی** (با زدن روی بازی)
* **رویدادها** — گل، کارت و تعویض به ترتیب دقیقه
* **آمار** — مالکیت توپ، شوت، کرنر و… با نمودار میله‌ای
* **ترکیب** — یازده نفر اول، نیمکت و سرمربی
* **رویارویی** — دیدارهای گذشتهٔ دو تیم با خلاصهٔ برد و باخت
* نوار پیشرفت بازی و دکمهٔ هم‌رسانی

**پروفایل تیم** (با زدن روی نام تیم در پنجرهٔ بازی)
* بازی‌های اخیر و بازی‌های پیش‌رو
* دکمهٔ «دنبال کردن تیم»

**دنبال‌کردن**
* ستارهٔ کنار هر بازی، برای دنبال‌کردن همان بازی
* دنبال‌کردن یک **تیم**؛ همهٔ بازی‌هایش بالای صفحه سنجاق می‌شود
* بخش جداگانهٔ «دنبال‌شده‌های شما» در بالای فهرست

**اعلان گل**
* پیام روی صفحه و چشمک‌زدن نتیجه در لحظهٔ گل
* **صدای گل** (اختیاری، بدون فایل صوتی — با وب‌آدیو ساخته می‌شود)
* **اعلان مرورگر** حتی وقتی صفحه باز نیست (با اجازهٔ کاربر)
* حالت «فقط دنبال‌شده‌ها» برای اینکه هر گلی خبر ندهد

**تنظیمات** (آیکون چرخ‌دنده در بالای صفحه)
* روشن/خاموش کردن صدا، اعلان و «فقط دنبال‌شده‌ها»
* **بدون لو رفتن نتیجه** — نتیجه پنهان می‌ماند تا روی آن بزنید
  (برای وقتی بازی را ضبط کرده‌اید)
* **نمایش فشرده** — بازی‌های بیشتر در یک صفحه
* انتخاب فاصلهٔ به‌روزرسانی: ۱۰ / ۲۰ / ۳۰ / ۶۰ ثانیه

**تجربهٔ کاربری**
* به‌روزرسانی خودکار همراه با حلقهٔ شمارش معکوس
* **نشانی اشتراکی** — هر بازی، تیم، جدول و روز نشانی خودش را دارد
  (مثلاً `#match/123`) و با دکمهٔ برگشت مرورگر هم کار می‌کند
* **میان‌برهای صفحه‌کلید**: `R` به‌روزرسانی، `/` جست‌وجو، `L` فقط زنده،
  `T` پوسته، `S` تنظیمات، `←/→` تغییر روز، `Esc` بستن
* **کشیدن به پایین برای تازه‌سازی** روی موبایل
* دو پوسته: **روز (پیش‌فرض)** و **شب** — با دکمهٔ بالای صفحه عوض می‌شود
  و انتخاب کاربر ذخیره می‌ماند
* راست‌چین و کاملاً فارسی، با اعداد فارسی و تقویم شمسی
* واکنش‌گرا: روی موبایل، تبلت و دسکتاپ (روی موبایل منو به پایین می‌رود)
* قابل نصب روی گوشی مثل اپلیکیشن (PWA) و باز شدن در حالت آفلاین
* انیمیشن‌های نرم، با احترام به تنظیم «کاهش حرکت» سیستم‌عامل

**فنی**
* کلید API هیچ‌وقت به مرورگر نمی‌رسد (همه‌چیز از سرور رد می‌شود)
* کش فایل‌محور — بدون نیاز به دیتابیس
* اگر سرویس بیرونی قطع شود، آخرین دادهٔ سالم نمایش داده می‌شود
* اگر هاست cURL نداشت، خودکار سراغ روش دوم می‌رود

## ۵) شخصی‌سازی

### تغییر رنگ اصلی

در ابتدای `assets/css/style.css`:

```css
:root {
  --brand:        #30933B;   /* رنگ اصلی (از لوگو گرفته شده) */
  --brand-bright: #46BE55;   /* حالت روشن‌تر */
  --live:         #FF4155;   /* رنگ بازی زنده */
}
```

### تغییر پوستهٔ پیش‌فرض

سایت به‌صورت پیش‌فرض با **پوستهٔ روز** باز می‌شود. برای اینکه پیش‌فرض
شب باشد، دو جا را عوض کنید:

`index.html` — خط اول:

```html
<html lang="fa" dir="rtl" data-theme="dark">
```

`assets/js/app.js` — داخل `Settings.defaults`:

```js
theme: 'dark',
```

### تغییر فاصلهٔ به‌روزرسانی

در ابتدای `assets/js/app.js`:

```js
var REFRESH_SEC = 20;   // ثانیه
```

### تغییر لیگ‌های منتخب و ترتیب آن‌ها

در `api/config.php` — لیگ‌های بالاتر، بالاتر نمایش داده می‌شوند:

```php
'featured_leagues' => [2, 3, 39, 140, 135, 78, 61, 88, 94, 203, 290],
```

شناسه‌های پرکاربرد API-Football:

| لیگ | شناسه |

| لیگ قهرمانان اروپا | ۲ |
| لیگ برتر انگلیس | ۳۹ |
| لالیگا | ۱۴۰ |
| سری آ | ۱۳۵ |
| بوندسلیگا | ۷۸ |
| لوشامپیونه | ۶۱ |
| لیگ برتر خلیج فارس | ۲۹۰ |

### تغییر منطقهٔ زمانی

```php
'timezone' => 'Asia/Tehran',
```

## ۶) رفع اشکال

| مشکل | علت و راه‌حل |
|---|---|
| صفحه سفید است | نسخهٔ PHP را در cPanel روی **۷٫۴ یا بالاتر** بگذارید (MultiPHP Manager) |
| خطای ۵۰۰ | فایل `.htaccess` را موقتاً به `htaccess.txt` تغییر نام دهید و دوباره امتحان کنید |
| نتایج تازه نمی‌شود | مقدار `cache_write` را در آدرس `health` ببینید؛ اگر `false` بود سطح دسترسی `api/cache` را ۷۵۵ کنید |
| «کلید API معتبر نیست» | کلید را دوباره کپی کنید؛ دقت کنید فاصلهٔ اضافه نداشته باشد و `host` با نوع کلید بخواند |
| «سهمیهٔ درخواست تمام شده» | مقدارهای `cache` را بالا ببرید (بخش ۳) |
| فونت درست نیست | مطمئن شوید پوشهٔ `assets/fonts` هم آپلود شده است |
| تغییرات را نمی‌بینم | یک‌بار با `Ctrl + Shift + R` صفحه را کامل تازه کنید (سرویس‌ورکر نسخهٔ قبلی را کش کرده) |

برای دیدن خطای دقیق، موقتاً در `api/config.php` مقدار زیر را عوض کنید:

```php
'debug' => true,
```

بعد از رفع مشکل حتماً دوباره `false` کنید.
